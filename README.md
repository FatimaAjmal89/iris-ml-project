# 🌸 Iris Flower Classification System

An end-to-end Machine Learning workspace analyzing, preprocessing, and classifying flower species (*Setosa*, *Versicolor*, and *Virginica*) using multiple supervised learning algorithms.

---

## 📌 Project Overview
The **Iris Flower Classification** project demonstrates a complete Data Science pipeline—from raw data exploration and visualization to model training, hyperparameter evaluation, and comparative performance analysis. 

Using classic morphological measurements (sepal length, sepal width, petal length, and petal width), the system trains and compares multiple classification models (**Logistic Regression**, **Gaussian Naive Bayes**, and **K-Nearest Neighbors**) to accurately predict the species of target flowers.

---

## 🎯 Key Objectives
* **Feature Engineering & Preprocessing:** Scale features and partition data using stratified splits to avoid dataset shift.
* **Model Benchmark:** Build and train multiple supervised models to evaluate accuracy across algorithms.
* **Performance Evaluation:** Measure model performance using Precision, Recall, F1-Score, Accuracy, and Confusion Matrices.
